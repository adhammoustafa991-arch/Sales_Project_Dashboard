Overview

This repository contains a comprehensive Sales Dashboard project designed to analyze and visualize sales performance metrics. The dashboard provides actionable insights into revenue generation, customer purchasing trends, geographic distribution, and year-over-year growth for the period between 2018 and 2021.

Files Included

Sales_Project_Dashboard.xlsx: The primary data and reporting file containing the data model, report layout, and metrics. (Note: This file contains the underlying data structures and reporting engine components).

Sales_Project_Dashboard.pdf: A static snapshot of the dashboard, providing a quick visual reference for stakeholders without requiring access to the reporting software.

Key Metrics & KPIs

Based on the dashboard reports, the following high-level metrics are tracked:

Total Sales: $172,800,307

Overall Year-over-Year (YOY) Growth: ~15.16%

Highest Revenue Category: Novelty Shops ($124M)

Timeframe Analyzed: 2018 - 2021

Dashboard Visualizations

The dashboard features several key visuals to help stakeholders understand the data from multiple angles:

Yearly Filter (Slicer): Allows users to filter data across specific years (2018, 2019, 2020, 2021).

Quantity by Month: A line chart displaying seasonal trends and the volume of items sold throughout the year.

Sales by Customer Category: A bar chart breaking down revenue by customer type. Categories include:

Novelty Shop (Top Performer)

Supermarket

Gift Store

Computer Store

Corporate

Detailed Sales Table: A tabular breakdown by month showing:

Sum of Sales

Sales YOY % (Year-over-Year growth)

Sales YTD (Year-to-Date)

Sales by Province: A map visualization highlighting sales distribution across the United States.

How to Use

Quick Review: Open Sales_Project_Dashboard.pdf to see a finalized snapshot of the report and its insights.

Data Exploration: Download Sales_Project_Dashboard.xlsx to interact with the underlying data model, apply filters, and explore the metrics in depth.
